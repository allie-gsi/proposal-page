# proposal-page

The client's Accept page for Green Services proposals, shown at proposals.mygreenservices.com.

This repo holds ONLY the page file (`index.html`) and the address file (`CNAME`). It holds no customer data, no prices, no names, no emails, no keys and no proposal links.
The page opens a proposal by asking the Green Services proposal service for it, using the long link code in the address. If that service is turned off, the page says so in plain words.

Nothing secret may ever be added here. The repo is public on purpose (free hosting).
